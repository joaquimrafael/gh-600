# Microsoft Learn

O workspace usa o Microsoft Learn MCP Server para consultar documentação oficial e exemplos atualizados.

- [Visão geral do Learn MCP Server](https://learn.microsoft.com/en-us/training/support/mcp)
- [Como começar no VS Code](https://learn.microsoft.com/en-us/training/support/mcp-get-started)
- [Referência do servidor e ferramentas](https://learn.microsoft.com/en-us/training/support/mcp-developer-reference)
- [Conteúdo de treinamento](https://learn.microsoft.com/en-us/training/)

Ferramentas disponíveis no MCP:

- `microsoft_docs_search`: pesquisar documentação
- `microsoft_docs_fetch`: buscar um artigo completo
- `microsoft_code_sample_search`: pesquisar exemplos de código

Antes de montar uma trilha, confirme aqui o nome completo ou o link oficial do GH-600.
