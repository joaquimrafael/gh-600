# Instrucoes para agentes

## Objetivo

Este repositorio e um caderno pratico para estudar o curso GH-600T00-A, Desenvolvimento em sistemas de IA agentica, e aplicar os conceitos em workflows do GitHub.

## Ponto de entrada

1. Leia `README.md`.
2. Consulte `docs/session-status.md` para saber onde continuar.
3. Siga `docs/roadmap.md`.
4. Leia o resumo do modulo do curso atual em `docs/`.
5. Use o mapa do roteiro para resolver ou avançar o exercicio do dominio da prova correspondente em `exercises/`.

## Nomenclatura

- **Modulo do curso**: uma das seis etapas das duas trilhas de aprendizagem do GH-600T00-A.
- **Dominio da prova**: uma das seis areas de habilidades avaliadas no exame GH-600.
- Nao trate modulo e dominio como equivalentes. Consulte o mapa cruzado em `docs/roadmap.md`, pois a ordem e o agrupamento dos assuntos sao diferentes.

## Estrutura

- `docs/`: resumos dos modulos do curso, conceitos, duvidas e decisoes de estudo
- `exercises/`: checkpoints praticos por dominio da prova
- `examples/`: evidencias, experimentos e solucoes reproduziveis
- `resources/`: fontes oficiais e referencias
- `.vscode/mcp.json`: configuracao do Microsoft Learn MCP Server

## Regras de trabalho

- Preserve o escopo de um repositorio de estudos; nao introduza framework ou dependencia sem necessidade.
- Use fontes oficiais quando explicar conteudo do GH-600.
- Se o Microsoft Learn MCP estiver disponivel, use `microsoft_docs_search` para localizar fontes e `microsoft_docs_fetch` para ler paginas completas.
- Se o MCP nao estiver disponivel, use os links ja registrados em `docs/roadmap.md` e `resources/microsoft-learn.md`, sem inventar conteudo.
- Registre a fonte oficial no resumo ou exemplo criado.
- Atualize `docs/session-status.md` ao concluir um modulo do curso, avancar a cobertura de um dominio da prova ou mudar o proximo passo.
- Mantenha alteracoes pequenas e explique o que foi aprendido.
- Nao armazene tokens, chaves, credenciais ou dados pessoais no repositorio.
- Antes de encerrar, valide links locais e a estrutura Markdown quando houver mudancas documentais.

## Fluxo de continuidade

Quando assumir uma tarefa:

1. Leia o estado atual.
2. Declare qual modulo do curso, dominio da prova ou artefato sera trabalhado.
3. Pesquise a fonte oficial, se necessario.
4. Edite apenas os arquivos relacionados.
5. Valide os links e atualize o estado.
6. Informe o proximo passo concreto.
