# Visão geral

## Objetivo

Aprender a projetar, implementar, avaliar, governar e operar sistemas de IA agêntica dentro de processos de desenvolvimento baseados em GitHub.

## Ambiente

- Sistema operacional: macOS
- Ferramentas: VS Code, GitHub Copilot e Microsoft Learn MCP
- Versões: registrar conforme forem usadas

## Conceitos para estudar

- [ ] Arquitetura de agentes e processos do SDLC
- [ ] Ferramentas, ambientes e interacao com o agente
- [ ] Memoria, estado e execucao
- [ ] Avaliacao, analise de erro e ajuste
- [ ] Coordenacao de varios agentes
- [ ] Guardrails, seguranca e prestacao de contas
