# Visão geral

## Objetivo

Aprender a projetar, implementar, avaliar, governar e operar sistemas de IA agêntica dentro de processos de desenvolvimento baseados em GitHub.

## Estruturas de estudo

- A sequencia de leitura segue os seis **modulos do curso GH-600T00-A**, distribuidos em duas trilhas.
- A verificacao de cobertura segue os seis **dominios da prova GH-600**, com pesos definidos no guia de estudo.
- Modulos e dominios nao possuem correspondencia um para um. O [roteiro](roadmap.md) registra o mapa entre eles.

## Ambiente

- Sistema operacional: macOS
- Ferramentas: VS Code, GitHub Copilot e Microsoft Learn MCP
- Versões: registrar conforme forem usadas

## Dominios da prova para estudar

- [x] Arquitetura de agentes e processos do SDLC
- [x] Ferramentas, ambientes e interacao com o agente
- [x] Memoria, estado e execucao
- [x] Avaliacao, analise de erro e ajuste
- [x] Coordenacao de varios agentes
- [x] Guardrails, seguranca e prestacao de contas
